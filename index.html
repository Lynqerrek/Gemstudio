GemStudio Docs

Complete dictionary of all commands. Tip: Edit code boxes below before copying!

Creation & Basics

CREATE

Makes a new object. Format: Name X Y W H.

CLONE

Duplicates an existing object.

DESTROY

Removes an object from the game.

COLOR

Sets the color (use Hex code).

TEXTURE

Sets image. Use name saved in Pixel Artist.

Physics & Movement

PHYSICS

Enables gravity and velocity for object.

SOLID

Makes object a solid wall/floor (blocks others).

VELOCITY

Sets constant speed instantly (X Y).

ADD_VEL

Pushes the object (adds to current speed).

MOVE

Teleports object by X Y pixels.

ROTATE

Rotates object by degrees.

GRAVITY

Sets global gravity pull (default 0).

FRICTION

Air resistance (0.0 - 1.0). Lower is slippery.

Controls & Logic

IF_KEY

Runs code if key held (SPACE, UP, DOWN, LEFT, RIGHT, WASD).

IF_CLICK

Runs code if mouse clicked. Use 'mouse_x' and 'mouse_y'.

IF_COLLIDE

Runs code if two objects touch.

IF_GROUNDED

Runs code if object is standing on a solid.

Audio & Effects

PLAY_SOUND

Plays a sound effect. Options: jump, coin, explosion, hit, powerup.

PARTICLE

Spawns an explosion of dots at X Y. Format: X Y Count Color.

FILTER

Applies screen effect. Try: 'blur(5px)', 'sepia(1)', or 'none'.

CAM_FOLLOW

Makes the camera center on this object.

CAM_ZOOM

Sets camera zoom level. 1.0 is default.

CAM_SHAKE

Shakes the screen with intensity.

UI & Data

UI_TEXT

Draws text. Use underscores for spaces. Use $var for data.

SET

Creates or changes a variable.

ADD

Adds a number to a variable.

SAVE_GAME

Saves variables to local storage.

LOAD_GAME

Loads variables from local storage.

LOG

Prints a message to the small console.
