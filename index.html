VoxelScript Documentation

Objects & Creation

Commands to spawn 3D objects in the scene.

cube x y z size color [name:id]
cube 0 1 0 1 red name:myBox
sphere x y z size color [name:id]
sphere 2 2 0 0.5 blue
plane x y z size color [name:id]
plane 0 0 0 10 #333 name:floor
light x y z color [intensity:n]
light 0 5 0 white intensity:2
label x y z "Text" color size
label 0 2 0 "Start" yellow 1.5
Logic & Flow

Control execution flow and define logic.

var name = value
var speed = 0.5
set name = expression
set speed = $speed + 0.1
wait seconds
wait 1.5
loop count iterator { ... }
loop 5 i { cube $i 0 0 1 red }
if condition { ... }
if $score > 10 { print 'Win!' }
func name { ... }
func jump { move player 0 1 0 }
call name
call jump
Manipulation

Change object properties over time.

move name x y z
Moves object relative to current position.
move player 0 0.1 0
teleport name x y z
Moves object to absolute position.
color name newColor
color myBox green
destroy name
destroy enemy
prop name key value
Change material props (metalness, roughness, opacity).
prop cube1 metalness 0.8
Physics & Animation

Add life to your objects.

spin name x y z
Continuous rotation speed.
spin coin 0 0.1 0
bounce name speed amp
Float up and down (Sine wave).
bounce item 2 0.5
physics name true
Enable simple gravity/floor collision.
Interaction & IO

Handle user input and output.

input key "code"
input w "move player 0 0 -0.5"
event name click "code"
event btn click "call startGame"
print "Message"
print 'Score: ' + $score
sound freq type
Types: sine, square, sawtooth, triangle.
sound 440 sine
Math Functions

Use in any numeric field or variable.

  • random(min, max)
  • sin(value)
  • cos(value)
  • Standard math: + - * /
